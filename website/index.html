02

Decisions, not decoration

先回答會改變行動的問題

圖譜不是比較潮的 CMDB。每個 use case 都必須連到一個能執行的安全決策。

P0APPSEC

Finding → Workload → PCI data

把弱點嚴重度與暴露面、business criticality、身分可達性合併，先修真正能形成路徑的洞。

Internet→Workload→Data
P0IAM

Identity → Privileged role → Crown jewel

找出群組、service principal、AWS role 與 SaaS entitlement 形成的間接管理權。

P0OWNERSHIP

Finding → Repo → Owner

把 Snyk finding 連回 repo、pipeline、deployed workload 與 application owner，避免工單流浪。

P1JML

Mover／Leaver residual access

以 Workday 狀態為權威來源，列出已離職或轉職人員仍保留的高風險存取。

P1GRC

Control → Evidence → Framework

讓 PCI、NYDFS、GLBA、SOX 控制覆蓋可抽樣、可追溯，也能看見證據是否過期。

P1SOC

Incident context enrichment

讓 Sentinel incident 快速取得 identity、asset、known weakness 與 owner 脈絡。

06

Storage decision

先 benchmark，再談信仰

Local 用 canonical JSON 驗證契約；production 預設候選為 Neptune，Neo4j 與 AGE 依實測條件進場。

方案最強項主要代價適用條件決策
Amazon NeptuneAWS managed controls、VPC、KMS、IAMopenCypher 差異、低流量也有底價小團隊、金融業 production預設候選
Neo4jCypher、GDS、分析工具成熟License／vendor 與網路治理Path analytics 生產力明顯勝出Benchmark
PostgreSQL + AGESQL 與 graph 共存Production extension、HA、patch 維運已有可靠自管 PostgreSQL 平台條件式

注意：不能假設 Amazon RDS PostgreSQL 可直接安裝任意 Apache AGE extension。免費 license 不等於免費營運，這個坑通常很會吃人月。

07

Explainable risk

分數可以拆，路徑可以驗

Risk score 不是 breach probability。每個 factor、control reduction 與 path evidence 都必須能被 reviewer 重建。

RISK MODEL v10—100
inherent = 0.25 × severity + 0.20 × exploitability + 0.20 × exposure + 0.25 × asset_criticality + 0.10 × identity_reach residual = inherent × (1 − 0.60 × control_reduction)

Control reduction 必須有新鮮證據，且最大折減 60%。簡報上畫了一個盾牌，不代表 critical finding 自動洗成 low。
