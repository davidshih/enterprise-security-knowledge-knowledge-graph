Storage decision

Benchmark first.
Believe later.

Local 先用 canonical JSON 驗證契約；production 再用相同資料集比較 managed controls、查詢能力與三年總成本。

Default candidate

Amazon Neptune

最適合小型金融業團隊的 managed operations、VPC、KMS 與 IAM 整合。

  • Managed Multi-AZ
  • AWS-native governance
  • Benchmark openCypher gaps
Graph analytics

Neo4j

當 Cypher、GDS 與 analyst productivity 的價值明顯勝過額外治理成本。

  • Mature graph tooling
  • Strong path analytics
  • Review license and network
Conditional

PostgreSQL + AGE

只有在團隊已有可靠 extension 自管平台，且 SQL/graph 共置是硬需求時採用。

  • SQL proximity
  • Higher operations burden
  • Do not assume RDS support
